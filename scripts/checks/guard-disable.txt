# C.1, boot 3 of 4 (after commit-flow.txt and guard-live.txt, through the wrapper): disables the guard pack of the
# committed world the way a player with cheats would. Vanilla keeps it on the world's disabled list at stop, so the
# next boot doesn't enable it by itself. Run the boots through the wrapper, in order (its default):
#   LOADER=<fabric|neoforge|forge> NODE=<1.21.11 (fabric only)|26.1.2|26.2|26.3> bash scripts/commit-smoke.sh
@sh sleep 5
datapack disable "file/commitment_guard.zip"
datapack list available
@expect Commitment: world world is committed; heartbeat on
@expect Disabling data pack .*file/commitment_guard\.zip
@expect There are [0-9]+ data pack\(s\) available: .*file/commitment_guard\.zip
